# Cancio Orders — Painel do Restaurante v1

MVP visual e funcional para demonstração.

## Como testar
Abra `index.html` no navegador ou publique a pasta em GitHub/Vercel.

## O que já funciona
- Dashboard
- Pedidos de demonstração
- Filtros por origem
- Fluxo de status
- Cadastro manual de pedido
- Resumo por origem
- Histórico básico
- Layout responsivo
